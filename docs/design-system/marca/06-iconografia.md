# Mi Puestito · Iconografía

## Regla
Ícono + nombre + para qué sirve. El ícono jamás reemplaza la palabra ni cambia entre versiones.

## Valores
| Tema | Decisión |
|---|---|
| Menú | "Fiados · Quién te debe": ícono, nombre y para qué sirve |
| Accesos de la caja | grandes, con dibujo, nombre y explicación |
| Controles | mínimo 56 px de alto en Normal |

## Así sí / Así no
- Así sí: el mismo ícono en todas las versiones
- Así no: menús de tres puntos o gestos escondidos

## Para el modelo
- Cada ícono va con su nombre y para qué sirve; nunca cambia entre versiones ni reemplaza la palabra.
