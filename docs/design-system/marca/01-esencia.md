# Mi Puestito · Esencia

## Regla
Mi Puestito es la app de los vendedores informales del Perú para llevar ventas, fiados, compras y caja. Se ve como un
**mercado**: cálida, familiar y fácil, para personas con poca experiencia con la tecnología.

## Valores
| Tema | Decisión |
|---|---|
| Público | Vendedores informales, muchos con baja fluidez lectora o mayores |
| Personalidad | Cercana, paciente, clara |
| Concepto visual | Paleta A "Mercado": fondo hueso, marrones cálidos y el color solo para el dinero |
| Dispositivo | Tablet primero; también teléfono y computadora |

## Así sí / Así no
- Así sí: lo frecuente, primero y grande
- Así no: pantallas densas de sistema contable
